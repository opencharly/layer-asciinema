# 2026.246.1622 — feat(asciinema): render .cast recordings to animated GIFs with agg (record: gif engine)

## Summary

The asciinema candy now also installs the **agg gif generator** (asciinema/agg, pinned v1.9.0) as a prebuilt binary at `/usr/local/bin/agg` plus a monospace font (DejaVu Sans Mono, per-distro via `package_map`: dejavu-sans-mono-fonts / ttf-dejavu / fonts-dejavu-core) so a stopped `.cast` recording can be rendered to an animated GIF — the engine behind the `record: gif` method (opencharly/plugin-record#5). agg is NOT a distro package (absent from RPM/DEB/PAC repos — verified against packages.fedoraproject.org, packages.debian.org, and the AUR), so the candy downloads the pinned prebuilt release binary via the `download:` verb; the font IS a distro package. Three new checks: binary present, `agg --version`, and a functional conversion of a minimal asciicast to a .gif (proving the binary AND the font work — agg fails with "no faces matching font family options" in a font-less container, root-caused by testing on fedora:43/archlinux/debian:13 base images).
